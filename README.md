# image-marker（画像マーカー）

画像に **用途別の色付き丸＋連番** や **星マーク**・**テキスト** を置いて、PNGで書き出すためのシンプルなツールです。
制作の指示書づくりで「ここは画像」「ここはムービー」「ここはリンク」といった箇所を、番号つきで伝えたいときに使えます。

ビルド不要・サーバー不要。`index.html` をブラウザで開くだけで動きます。
画像はブラウザ内だけで処理され、どこにもアップロードされません。

**公開URL（GitHub Pages）：https://fcl-maruyama.github.io/image-marker/**
ブラウザで開けばそのまま使えます（インストール不要）。

## ツール

| マーク | 用途 | 中身 |
| --- | --- | --- |
| ★ 黄色の星 | 画像切り替え | 番号なし |
| 赤丸 | 画像 | 連番（1, 2, 3 …） |
| 青丸 | ムービー | 連番 |
| ピンク丸 | アンカーリンク | 連番 |
| ピンク枠の白丸 | アンカー先 | 連番 |
| 緑丸 | ボタン | アルファベット（A, B … Z, AA, AB …） |
| T | テキスト入力 | クリックした場所に文字を置く |

- 連番・アルファベットは **種類ごとに別々** に数えます（赤の3番と青の3番は別物）。
- 各ツールの横の欄で **開始番号・開始文字** を指定できます（例：5から、Cから）。
  アンカーリンクとアンカー先も別々に指定できるので、移動先が別の画像にあるときも番号を合わせられます。
- 番号は **全パネルを通して置いた順** に振られます。
- マークと文字の大きさは、画像の大きさに合わせて自動で調整されます。

## 使い方

1. `index.html`（または公開URL）をブラウザ（Chrome / Edge など）で開く
2. 各枠を **クリック** するか、画像を **ドラッグ＆ドロップ** して読み込む
3. ツールバーで置きたいマークを選ぶ（必要なら開始番号を変える）
4. 画像上を **クリック** してマークを置く
5. 「PNGで保存」で書き出す

## 操作一覧

| 操作 | 内容 |
| --- | --- |
| 画像の読み込み | 空枠をクリック、または画像をドロップ |
| パネルの追加 | 右端の「＋」（最初は3枚・最大8枚。横に並び、上下のバーで横スクロール） |
| マークを置く | 画像をクリック（選択中のツールで設置） |
| テキストを置く | 「T」を選んで画像をクリック → 入力。`Enter` で確定・`Shift+Enter` で改行・`Esc` で取りやめ |
| 取り消し | 「取り消し」ボタン または `Ctrl+Z`（全パネル共通で直前の1つ） |
| 全消し | すべてのマークを消去 |
| PNGで保存 | 画像のあるパネルをそれぞれPNGで書き出し（`01.png`, `02.png` …） |

## 技術メモ

- HTML / CSS / JavaScript のみ（依存ライブラリなし・全部 `index.html` 1ファイル）
- Canvas API で画像とマークを描画
- 表示縮小ぶんを補正してクリック座標を実サイズに変換するため、大きい画像でも位置がずれません
